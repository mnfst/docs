## What you saw

```text
[🦚 Manifest M204] Manifest Cloud needs a Pro subscription to route requests. Subscribe here: https://app.manifest.build/upgrade?reason=requests
See https://manifest.build/llm-gateway/docs/errors/M204
```

SDK and tool callers receive an HTTP 402 JSON error with `error.code` set to `PLAN_LIMIT_REQUESTS`:

```json
{
  "error": {
    "message": "[🦚 Manifest M204] Manifest Cloud needs a Pro subscription to route requests. Subscribe here: https://app.manifest.build/upgrade?reason=requests",
    "type": "insufficient_quota",
    "code": "PLAN_LIMIT_REQUESTS"
  }
}
```

## Why it happened

Your LLM Gateway Cloud workspace has no active Pro subscription. Since November 2, 2026, Manifest Cloud is $19/month with unlimited routed requests, and a workspace without a subscription does not route requests. The check runs before any provider is contacted, so nothing was sent and nothing was spent. Your dashboard, harnesses and settings are kept.

This is a Cloud plan restriction, not a provider error and not a limit you configured on a harness.

## How to fix it

1. Subscribe from the dashboard link in the error message. Routing resumes as soon as the subscription is active.
2. Or run the gateway yourself: the [self-hosted](/llm-gateway/docs/self-hosted) gateway is free, has no request limit and never returns M204.
