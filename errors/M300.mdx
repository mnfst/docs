## What you saw

```text
[🦚 Manifest M300] `messages` array is required.
See https://manifest.build/llm-gateway/docs/errors/M300
```

## Why it happened

The OpenAI-compatible chat completions API requires a `messages` array with at least one entry. The gateway received a body where `messages` was missing, not an array, or empty.

## How to fix it

Send a body shaped like this:

```json
{
  "model": "auto",
  "messages": [
    { "role": "user", "content": "Hello" }
  ]
}
```

The OpenAI SDK handles this for you. If you're hand-rolling the request, eyeball the JSON before posting.
